They were collected after integrating the source runner with a fresh public CuTe DSL installation; earlier standalone timings are not reused. ## Timing and scope

Both implementations use CUPTI concurrent GPU activities through the PyTorch profiler. Five eager warmups precede capture of 16 complete calls per graph, followed by three warmup graph replays and three profiled replays. Each sample is `(last GPU activity end - first GPU activity start)/16`; the median is reported. Overlapping activity durations are not summed. Compilation, initialization, input preparation, and reference evaluation are excluded. The largest three-sample spread divided by its median was **2.92%** across both implementations. Repeatability does not establish absolute timing accuracy; profiling can perturb execution.

The pinned upstream input generator supplies all 171 configurations with seed 42 and the official normalized-Q/K, mixed-decay, sigmoid-beta input recipe. CUDA IPC shares the exact inputs between workers. Q/K/V are BF16; gates, beta, initial states and final states are FP32; key and value dimensions are 128. These results measure profiled steady-state forward time per call, not isolated latency, CPU dispatch overhead, model throughput, or training performance. They are not directly interchangeable with earlier event-timed measurements.

The numerical policy retains conditional small-transition truncation, an approximation. This workload's passing error gate is not a universal guarantee for arbitrary input magnitudes. Candidate-versus-baseline errors are diagnostic; acceptance compares each implementation independently with the FP32 reference.

See [README.md](README.md) for requirements and the exact reproduction command. `benchmark_results.json` contains all per-case sample spans and activity counts. `measurement.json` records measured code digests; the reproduction command writes full individual GPU activity records.

Nine reference tests passed with 159 public compiler deprecation/static-loop warnings; no numerical gate was relaxed. A CUDA IPC lifetime warning was emitted during worker teardown after measurements completed; the benchmark exited successfully.
